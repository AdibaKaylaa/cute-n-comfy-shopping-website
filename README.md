# Cute 'n' Comfy Shopping Website

Cute 'n' Comfy is a shopping website I built as a front-end web development project. The site focuses on cute and comfortable fashion products and includes multiple pages for browsing products, viewing product details, accessing an account page, and viewing a shopping cart.

## Live Website

[View the website](https://adibakaylaa.github.io/cute-n-comfy-shopping-website/)

## Built With

- HTML
- CSS
- A small amount of JavaScript for the responsive navigation menu

## Features

- Responsive navigation menu
- Featured and latest product sections
- Individual product details page
- Products page
- Shopping cart interface
- Account page
- Limited edition product page
- Responsive page layouts
- Custom styling, product cards, buttons, and navigation
- Google Fonts

## What I Learned

Building this project helped me practice creating a multi-page website, organizing HTML and CSS, working with responsive layouts, linking pages together, and designing a consistent interface across different pages.

## Running the Website Locally

Clone or download the repository and open `index.html` in a web browser.
